# `/forbid-appraisal` — re-read the bans

Gates that are each locally right can still stop the job. Keep those
sentences visible as **specimens** so they can be appraised.

<!-- LOCALISE: this tree's live table and telos. -->
**Live table:** [`docs/forbid_appraisal.md`](../../../docs/forbid_appraisal.md)
(create it if missing; do not grow refusals only in chat).
**Telos:** [`docs/PURPOSE.md`](../../../docs/PURPOSE.md).

| Disposition | Means |
|---|---|
| **keep** | Serves the telos. Still not a licence to generalise it. |
| **narrow** | True on one path; fatal if treated as the whole job. |
| **burn** | Stops the job. Do not obey. Amend the mouth that still says it. |

## Procedure

1. Hear the forbid as agents will obey it (one sentence).
2. Cite where it lived.
3. Open the telos.
4. Disposition keep / narrow / burn.
5. Write the row **before** obeying the sentence.
6. If burn: cut or amend the living mouth, or docket the cut.
7. Periodic pass: re-read keep and narrow against the telos.

## Reject list

- Obeying a new refusal with no table row.
- A row with no disposition.
- Treating the table as product law.
